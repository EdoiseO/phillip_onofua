# Developer stickers

The Code collection uses the same self-hosted vector brand marks as the portfolio Languages section in `assets/tech-logos/`:

- JavaScript, TypeScript, Python, HTML5 and CSS3: [Devicon](https://devicon.dev/), original SVG variants.
- C++: [Simple Icons](https://simpleicons.org/), C++ mark.

These six sticker SVGs preserve the logo artwork and add a warm-white cutout border. Python's source display shadow is omitted. They have transparent backgrounds and explicit 512 × 512 dimensions for WebGL texture decoding. No generated logo artwork or screenshot upscaling is used. Brand marks belong to their respective owners; no endorsement is implied.

The original six sticker PNGs remain unchanged.
