# Cardboard lining

Created using **Cardboard 002** by ambientCG (Lennart Demes), licensed under Creative Commons CC0 1.0 Universal.

- Asset: https://ambientcg.com/view?id=Cardboard002
- License: https://docs.ambientcg.com/license/
- Download: https://ambientcg.com/get?file=Cardboard002_1K-JPG.zip
- Included original maps: Color, NormalGL, Roughness, each 1024 × 1024 pixels.
- Filenames shortened for the application. The maps were re-encoded as JPEG at quality 90, keeping their original dimensions, to reduce loading time. The material applies a warm, less saturated tint and modest normal strength at render time.

A cardboard reference image informed the visual treatment; it is not embedded in the application.
