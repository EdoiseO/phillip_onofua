# Sticker system

The sticker studio lets me place and arrange stickers on the comic box. Stickers
wrap around vertical corners and stay attached to the lid as it opens. Gloss and
holographic finishes give each design a different surface treatment.

An arrangement holds up to 24 stickers. Undo keeps the last 20 changes for the
current session. Arrangements are saved in browser local storage and validated
when loaded; if storage is unavailable, the arrangement remains session-only.

Run the sticker tests from the repository root:

```sh
node --test off-the-clock/stickers.test.mjs
```
